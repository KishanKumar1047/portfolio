# Portfolio Website

Welcome to my portfolio website! This site showcases my skills, projects, and professional journey.

## Live Demo

Currently, the website is hosted locally at `http://localhost:5500/index.html`. To deploy it online, consider using platforms like GitHub Pages, Netlify, or Vercel.

## Features

- About Me Section
- Projects Showcase
- Contact Information
- Responsive Design

## Technologies Used

- **HTML** - Structure of the website
- **CSS** - Styling and layout
- **JavaScript** - Interactive elements

## How to Run Locally

1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/portfolio.git
   ```
2. Navigate to the project directory:
   ```sh
   cd portfolio
   ```
3. Open `index.html` in a browser or use a live server extension (VS Code recommended).

## Deployment

To deploy your portfolio online:
- Use **GitHub Pages**: Push your code to a GitHub repository and enable GitHub Pages in settings.
- Use **Netlify** or **Vercel** for easy deployment with custom domains.
